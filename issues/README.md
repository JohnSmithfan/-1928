> 注 4：同日（#234 D656）二十三份 Issue 正文的章节号自加八前的旧编号改回现行编号——改回的办法是**按章标题映射**，不按偏移量硬推（第一卷第四幕自身由十五章增至二十三章，幕内并非平移）。详见报告 #234 第五节。
