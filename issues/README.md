## 使用约定

- **开写前**：在本 Issue 下补充「待议问题」的决议，再动笔；决议如与大纲冲突，**先改 `notes-personal/大纲草稿.md`，审核通过后再同步 `worldbuilding/OUTLINE/` 定稿**（CONTRIBUTING §9.1）。
- **完稿后**：回填「结论记录」，并在 `progress.md` 更新卷/幕进度；一致性复核在本 Issue 内追加评论式记录。
- **章数与年份**：卷三/四/五已按约 38 章/年重排；卷一（约 20 章/年）、卷二（40 章/年）暂维持，如需全书统一另行开 Issue。
