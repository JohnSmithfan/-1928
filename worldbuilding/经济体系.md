# 经济体系

## 一、东北经济基础（1928年）

### 1.1 资源优势

- **矿产资源**：抚顺煤矿（亚洲最大煤矿之一）、本溪湖铁矿、钨矿（兴山）、锑矿、金刚石（金伯利岩管）
- **农业资源**：东北平原黑土地，粮食产量充足，大豆出口是重要外汇来源
- **工业基础**：东三省兵工厂（机器8000余部、员工2.1万人）、沈阳飞机制造厂、哈尔滨造船厂
- **人力资源**：东北人口约3000万，劳动力充裕且素质较高（受教育程度高于全国平均）

### 1.2 经济结构

- 农业占GDP约60%，工业约25%，服务业约15%
- 工业以军工、采矿、食品加工为主
- 对外贸易高度依赖对日贸易（大豆、煤炭出口，工业品进口）

## 二、工业化路线

### 2.1 中德易货贸易（核心引擎）

```
东北出口：钨砂 -> 德国进口：军工生产线
        锑矿 ->         精密机床
        大豆/煤炭 ->    工业设备
        皮革/毛皮 ->    化学工业技术
```

- **规模**：1930年代中德贸易额从几乎为零增长到每年数千万银元
- **关键协议**：《中德易货协定》（小说时间线提前至1929年）
- **德国顾问团**：以塞克特为原型的军事顾问团 + 工业技术顾问团

### 2.2 重点建设领域

1. **军工复合体**：兵工厂扩建→弹药自给→坦克/飞机自主生产
2. **钢铁工业**：本溪湖钢铁厂扩建 + 新建鞍山钢铁基地（参考历史上鞍钢）
3. **能源工业**：抚顺煤矿现代化改造 + 新建火电站
4. **交通运输**：南满铁路（控制下）+ 新建奉天-哈尔滨铁路 + 公路网
5. **化工工业**：以煤炭为原料的合成氨（化肥）、合成橡胶项目

### 2.3 时间线

| 年份 | 工业里程碑 |
|------|-----------|
| 1929 | 东三省兵工厂完成第一轮扩建，产能提升50% |
| 1931 | 沈阳飞机制造厂试制成功首架国产战斗机 |
| 1933 | 本溪钢铁厂年产钢突破10万吨 |
| 1935 | 东北军工实现轻武器完全自给，重武器自给率60% |
| 1937 | 全面抗战爆发时，东北工业体系可支撑百万级军队 |

## 三、农业与土地政策

### 3.1 渐进式改革路径

```
第一阶段（1932-1934）：减租减息
  - 限制地租不超过收成的37.5%
  - 禁止高利贷（年利率上限24%）
  - 成立农民协会，调解租佃纠纷

第二阶段（1935-1937）：限田与清算
  - 规定每户占地上限（如50公顷）
  - 清算汉奸、卖国贼的地产（获取合法性）
  - 政府赎买超额土地，分配给无地农民

第三阶段（1938-1942）：合作化
  - 推广农业生产合作社（自愿加入）
  - 合作社统一采购、统一销售，提高议价能力
  - 逐步将耕地收归集体经营
```

### 3.2 改革策略

- **合法性构建**：以"抗日需要""清算汉奸"为名推进，避免直接触动中小地主
- **利益交换**：给开明士绅政治参与渠道（地方议会席位），换取其对改革的支持
- **示范效应**：先在小范围试点成功，再用事实说服犹豫者

## 四、财政与税收

- **主要财源**：资源出口（钨锑）、工业税收、关税（控制港口后）
- **货币体系**：初期沿用银元/奉票，后期建立东北银行发行"东北券"
- **外汇管理**：严格外汇管制，确保进口关键设备的外汇优先

## 五、写作注意事项

- 经济描写容易枯燥，建议通过具体人物的经济活动来展现（如一个工厂厂长的视角）
- 注意时代合理性：1930年代没有计算机，经济计划靠人力计算和统计
- 战争对经济的破坏与重建可作为重要剧情线
