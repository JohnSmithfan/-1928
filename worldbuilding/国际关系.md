# 国际关系

## 一、中德关系（核心盟友）

### 1.1 合作基础

- **德国需求**：《凡尔赛条约》限制德国军备，需海外基地转移军工技术；急需钨、锑等战略矿产
- **中国需求**：需要现代化军事装备和工业技术来对抗日本
- **互补性**：德国的技术 + 中国的资源 = 双赢

### 1.2 合作内容

- **军事**：军事顾问团（塞克特派系）、武器进口、军事训练
- **工业**：重工业建设项目（钢铁、化工、机械）
- **贸易**：易货贸易，以矿产和农产品换取德国工业品

### 1.3 时间线

| 时间 | 事件 |
|------|------|
| 1928年 | 张学良接触德国驻华使馆，试探合作可能 |
| 1929年 | 秘密派遣代表团赴德，签订初步技术合作协议 |
| 1930年 | 德国军事顾问团抵达沈阳，开始整训东北军 |
| 1932年 | 中德贸易额大幅增长，多个工业项目开工 |
| 1934年 | 《中德易货协定》（合步楼条约）签署——**易货**合同，以钨锑与农产换工业品，**无政府信贷** |
| 1936年 | 《易货协定之补充贸易合同》签署，德方开立**一亿马克循环信用账户**（史实民国二十五年四月八日，顾振与沙赫特在柏林签）。**本线德国信贷自此起算**，不得记在 1934 年（#118） |
| 1938年 | 德国调停中日和谈（历史上真实事件），张学良拒绝，中德关系微妙 |
| 1941年 | 德国对美宣战，中德官方合作终止，但技术遗产已根深蒂固 |

## 二、中苏关系（复杂的合作者）

### 2.1 合作基础

- 苏联需要牵制日本（日本在远东对苏联构成威胁）
- 张学良需要苏联作为对抗日本的后盾
- 共产国际与东北方面的意识形态联系

### 2.2 矛盾与博弈

- 苏联对张学良既合作又防备，不愿看到东北过于强大
- 共产国际要求东北方面与中共加强合作，张学良对此警惕
- 中东铁路权益问题是双方长期博弈的焦点

### 2.3 关键事件

| 时间 | 事件 |
|------|------|
| 1929年 | 中东路事件（小说中可能不发生或形式不同） |
| 1930年代 | 苏联向东北提供有限军事援助 |
| 1945年 | 苏联对日宣战。出兵落点是**朝鲜北部、南库页与千岛**；中国方向至多协同。**不得写出兵东北**——本线东北从未丢失，苏军既无进入中国东北的名义，也无作战对象。三八线分区受降由此而来（#118） |

## 三、中日关系（死敌）

### 3.1 日本内部政治

- **军部激进派**：主张武力扩张，控制朝鲜和满洲
- **政府温和派**：希望维持东亚现状，与西方合作
- **天皇**：象征性元首，但在关键时刻有决定性影响力

### 3.2 日本的战略困境

- 资源匮乏，需要中国市场的原材料和商品
- 海军vs陆军的内耗（海军主张南进，陆军主张北进/大陆政策）
- 与美国、英国的潜在冲突

### 3.3 关键人物（可设定）

- 关东军司令官（系列反派，可多个人物轮换）
- 日本驻华大使（外交线角色）
- 日本陆军参谋本部战略家（智力型对手）

## 四、英美关系

### 4.1 美国

- **官方立场**：名义上支持中国主权，但实际上奉行孤立主义
- **民间态度**：同情中国抗日，飞虎队等民间援华力量活跃
- **经济因素**：美国企业对日贸易（石油、钢铁禁运前的事情）

### 4.2 英国

- **在华利益**：长江流域、香港殖民地
- **对华态度**：表面支持中国，实际不愿日本过于强大影响平衡
- **与苏联关系**：反共立场使其对苏联牵制日本持矛盾态度

### 5.1 战后国际格局（1945—1953，报告 #118 补）

> #116 补的是**兵种**分期（新增战后期 1946—1953），国际格局这一半当时没跟着补，于是同一册里兵力、炮兵、空军、海军都写到 1953、国际格局却停在 1945。本小节补上这八年。

| 年份 | 世界大事 | 本线口径 |
|---|---|---|
| 1945 | 联合国创建 | 中国以战胜国与创始会员国身份参与。本线东北未失 ⇒ 中国是完整交战国与战后秩序的**参与制定者**，不是被援助的对象 |
| 1946 | 中国军队自越北撤出、法军接管 | 见 `worldbuilding/地理与势力.md` §1.3 |
| 1947 | 冷战开局 | 本线对苏仍是「既利用又防备」（`worldbuilding/政治体系.md` §6.8），不受这条轴支配；但一切外援来路从此要写明出自哪一边 |
| 1948—1949 | 柏林封锁 | 欧洲的事，本线只作背景，不写中国卷入 |
| 1949.4 | 北约成立 | 同上，只作背景 |
| 1949.8 | 苏联首次核试验 | 本线红线仍是无核、无导弹（`worldbuilding/科技水平.md` §五），**这条不因蝴蝶效应放开** |
| 1950.6—1953.7 | 朝鲜战争 | 见下方硬口径 |
| 1953.3 | 斯大林逝世 | 与本线终卷同年，可提一笔，不展开 |
| 1953.7.27 | 朝鲜停战协定 | 同上 |

**【硬口径·朝鲜战争（#118）】**

1. **不预写进程与结局**——与 `worldbuilding/政治体系.md` §6.4「冷战与热战不预写」同一口径。1950 年 6 月以后半岛发生什么，本线一律不写。
2. **但 1944—1945 本线在半岛打过仗、受过降这件事必须交代**——那是本线自己打出去的事，不是战后的善后；两头都空等于没写。
3. **三八线分治只作留白，不作本线的账**——不写本线在分治中扮演什么角色、分到哪一侧。

## 六、写作注意事项

- 国际政治描写要避免过于简化，每个国家都有其复杂的利益计算
- 可以借用真实历史事件作为背景，但注意时间线的调整
- 外交戏码是很好的智斗素材——谈判桌上的博弈不亚于战场
- 注意不同国家的文化差异和思维方式差异
