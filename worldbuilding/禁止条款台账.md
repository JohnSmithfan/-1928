# 禁止条款台账（禁止条款：原因 · 限制范围 · 时间节点）

> **本文件的用途**：全库硬口径、红线、禁写条款散在 `军事体系.md`／`科技水平.md`／`经济体系.md`／`地理与势力.md`／`时间线.md`／`STYLE-GUIDE.md`／`SYNOPSIS.md` 与各卷大纲，条目多、出处杂。**本表只做一件事：把经评估后仍有效的条款（禁止条款）集中登记，逐条写明它为什么禁、禁到哪里为止、禁到什么时候。**
>
> **效力**：本表**不新增条款**，只登记既有的；条款原文与本表冲突时，**以条款原文所在文件为准**，本表负责索引与解释。**新写章节、改写旧章，凡撞上本表条目，先查原文再落笔。**
>
> **总判据（一条标准、三个问句，`科技水平.md` §5.1，2026-09-29 立）**：禁的是**当时拿不到、也做不出**的东西——①这项东西的原理与工艺，属不属于 1928—1953 这一段；②会不会改写世界史（**蝴蝶效应能顶开「中国没做到」，顶不开「世界当时没人做到」**）；③本线自己造得出来、原理与工艺都属于这一时代的，不属禁写。
>
> **废止机制**：条款不是不能改。**凡经史实、蝴蝶效应、SYNOPSIS 三维复核后判为不合理者，一律废止并登记进第八节留痕**（#264 废「西南的兵不出省」、#265 废「青霉素战时不可写／不得写航拍地质」即为其例）。

## 一、越代器物（丁档·终卷禁写）

> **共同原因**：原理与工艺不属于 1928—1953 这一段，或会改写世界史。**共同时间节点：1953 年终卷前一律禁写成品；可写提案、算账与否决。**

| 条款 | 原因 | 限制范围 | 时间节点 |
|---|---|---|---|
| 核、导弹、铀 | 会改写世界史；且「提案」这一笔本身就会把「核」这个名词放进正文 | **禁写，并禁写提案与否决** | 终卷前 |
| 喷气发动机（jet） | 航空接近美国水平仍不等于能做 jet；高温合金与风洞是另一条链 | 自产、外购、缴获三层全禁 | 终卷前（1953） |
| 雷达测距（火控用途） | 电真空与脉冲技术当时拿不到也做不出 | **禁的是火控测距，不是雷达本身**（见第二节雷达条） | 终卷前 |
| 电子计算机、激光、卫星、互联网 | 原理与工艺均不属这一段 | **全禁** | 终卷前。**其中电子式（电子管）计算机按 D857 收窄：禁至 1951 年底，1952 起放行，见下行** |
| **电子式**（电子管／晶体管）计算机 | 同上，**禁的是「电子式」这一物理形态，不是「计算机」这一门** | **机电式（电磁继电器）计算机不在禁内**——继电器是电话交换机的成熟件，民国二十年代起即用，本线能造能买；史实对位楚泽 Z3（1941，继电器、图灵完备）、Harvard Mark I（1944，机电式）、贝尔实验室 Model V（1946，继电器）。**冯诺伊曼架构（存储程序）是架构不是器件，可用继电器实现**（#272 D856） | **D857 定案：禁至民国四十年（1951）十二月三十一日；1952 起放行**，放行后只写一两台、仍禁晶体管、不得写比人快、不进指挥流程、代价按管计（#273）。机电式可写成品，见 `科技水平.md` §4.10 |
| 战略轰炸机（四发重爆）、海军轰炸机 | 本线不设这一格（海军只有水机中队） | 禁成品；可写提案与否决 | 终卷前 |
| 电子战机、箔条干扰、全网监听 | 电真空属丁档；本线电子对抗已定死为密码本、呼号轮换、通信纪律、电报管控与假电报 | 自产／外购／缴获三层全禁 | 终卷前 |
| 我方舰载机 | 无航空母舰即无舰载机；水机不是舰载机（吊臂收放） | 我方禁写，**敌方按 §1.5.5 甲档应写** | 终卷前 |
| 重型战舰（战列舰） | 史上中国从未有过；本线无此格 | 禁写，**包括「缴获的」** | 终卷前 |
| 航空母舰 | 判的不是有没有甲板，是**飞机怎么上去、怎么下来** | 甲档水机母舰可写、乙档立项不许成军、丙丁禁写 | 终卷前 |
| 潜艇、布雷潜艇 | 《凡尔赛条约》把潜艇列为德国禁造之物，是本线这一格的地基 | 禁写 | 终卷前 |
| 超重型穿甲弹 | 要 16 英寸炮、三万六千码射程与远程火控；本线三样都没有，**且「打谁的甲板」这个问题本线不存在** | 禁写 | 终卷前 |
| 磁性鱼雷／自主制导鱼雷 | 世界 1940 年挪威自己失灵、1942 年才修好；本线无平台、无器件、无需求 | 禁写 | 终卷前 |
| 磁性水雷／声学水雷／空中布雷／空中扫雷 | 同上；水机**看**雷区报方位可写（属既有的侦察与校射四样） | 禁写布雷与扫雷 | 终卷前 |
| 全地形车 | 器物与词双重越代（1960 年代后的中文分类词） | 禁写；可写提案与否决，**建议只留一句「有人提过」** | 终卷前 |
| 重型坦克 | 二十吨天花板 + 江南桥涵与路基 | **禁成品**，可写提案与否决；**正文不出现「重型」二字** | 终卷前 |
| 履带式自行火箭炮 | 本线车体是卡车，无履带底盘工业 | 禁写（无控多管火箭炮本身**有**，四个营四十八门） | 终卷前 |
| 坦克歼击车、架桥坦克／装甲工兵车、装甲炊事车 | 三问都过得去而仍判死：**造出来打谁**；且世界当时无此品种 | 禁成品，**不单列新提案** | 终卷前 |
| 硬式飞艇／载机飞艇／飞艇轰炸 | 美国阿克伦号 1931、梅肯号 1933，1933 与 1935 两次坠毁——**世界当时两次都没成** | 禁成品；可写提案与否决，否决理由固定三条（铝先给飞机厂、氢是氨厂的、兴登堡那一把火） | 终卷前 |
| 二炮、火箭军、远火旅 | 定义性装备是导弹（本线锁死无核无导弹），且番号越代（二炮 1966、火箭军 2015） | 禁写，**不补这一类兵种行** | 终卷前 |

## 二、时间闸门（到某年开禁）

> **共同原因**：世界当时已有、而本线当下还做不到；到点后可写，且**一律守「不得写量产／普及／取代既有办法」三句**。

| 条款 | 原因 | 限制范围 | 时间节点 |
|---|---|---|---|
| 国产航空发动机 | 高温合金与镍铬是本线的「绳子」，且需要长期试验积累 | **不许有**；1930 年建的是「发动机修理间」，1943 年仍是美援发动机 | **1953 年终卷前** |
| 飞机自主生产 | 厂不等于器；沈阳飞机制造厂 1929 年动工，厂立了九年才许写「自主」 | 1938 年前不得写自主（装／仿可写） | **1938 年起** |
| 坦克自主生产 | 同上（§9.2 硬锚） | 1937 年前不得写自主生产 | **1938 年下线** |
| 光学玻璃与精密仪表自产 | 工艺 Know-how 极强，蔡司 1930s 垄断 | 光学分厂**只装只修** | 自产不早于**战后**（第五卷） |
| 机床自给 | 进口机床到货以年计、近两成卡在半路；1931—1941 靠中德易货，1941 年后靠美援租借 | 战时机床**没有一天是自给的** | 自给在**战后**（第五卷第800章） |
| 独立研究院／设计局／研发部门 | 战时研究只挂在厂里、人不专职 | 禁写独立建制 | 研究院与研究所网在**战后** |
| 突击步枪 | 不在禁写，按年份与产能设限 | 1944 年前不得有实物；1945 起可写缴获与研究；自研立项不早于 1946；成军不早于 1950；**终卷装备比例为个位数，不得写全军换装** | 1944／1945／1946／1950 四档 |
| 磺胺 | 合成药不是发酵药（1908 合成、1932 百浪多息、1935 发表疗效） | 民国二十六年后可写小量自产，**产量以公斤计、先供军医**；不得写够用与普及、不得写它取代清创与隔离 | **民国二十六年（1937）后**；民国十七至二十年仍禁 |
| **青霉素** | **#265 改判**：民国三十三年昆明中央防疫处已制出中国第一批青霉素（**史实中国工业远弱于本线**），且与 G4（DDT）判据同型 | 民国三十三年后可写**极少量自制**（以克计、以百瓶计，先供重伤员与手术），菌种来路须写明；不得写量产／普及／取代清创与隔离 | **民国三十三年（1944）后**（三十二年前仍禁） |
| DDT 一类合成杀虫剂 | 1874 合成、1939 发现杀虫性、1942 商品化；**本线民国三十一年后与英美联合，这条路是开着的** | 可写**盟军提供的小量 DDT 用于灭虱防疫**，须写明来路；不得写自产、不得写农业与民用普及、不得写成它取代蒸汽／开水／剃发／隔离那四样 | **民国三十一年（1942）后** |
| 雷达整机 | 电真空与脉冲技术做不出 | 不得自产整机；民国三十三年后可有**个位数**预警雷达（盟军提供或缴获），须写明来路、不得写普及、不得写成它决定了任何一次防空战的胜负 | **民国三十三年（1944）后** |
| 机车自主 | — | 1946 年前不自主 | **1946 年**（第四卷第732章） |
| 汽车普及与民用轿车工业 | 战时钢、油、路三样都不允许 | 不得写民用轿车工业与汽车普及 | 战后（第五卷） |
| 钢筋混凝土**民用**建筑 | 民用钢人均十六公斤是硬账，战时钢与水泥先走军的路 | 战时禁写；**工厂、仓库、兵营、防空与公用建筑不在此列** | 战时（1937—1945）；战后放开 |
| 深井探油 | 德国汉内尔厂旋转钻机可钻 1200 米，松辽油层在 1357 米，**差一百五十七米** | 可写立项与开钻；**不得写见工业油流、不得写产油** | 终卷前（即本线**无大庆**） |
| 第四批各省人物登场 | 西南西北各省民国二十九至三十一年才进名分 | 名分未到不得登场（只能以电报里的名字、报单里的一行、别人嘴里的一句出现） | **民国二十九年（1940）后**；云南二十九／贵州三十／川康三十一 |

## 三、规模上限与能力边界

> **共同原因**：#252 丁档结论——**「赢一半」的写法是全卷最硬资产**（钢盔挡不住三八式／夹砂板 324kg 对钢板 152kg／一地拉不起三十架）。这些条款不是压低主角，是让赢赢得可信。

| 条款 | 原因 | 限制范围 | 时间节点 |
|---|---|---|---|
| 单车全重二十吨天花板 | 超过就要为它验算每一座桥、每一段路基、每一辆平板车。**这一条判死重型坦克，也禁止坦克泛水冲滩** | 机动车辆 | 终卷前 |
| 空运止于营级 | **判据是运力不是架数**：驼峰空运一吨货路上烧掉的油是它本身的数倍，一个师运不起，一个工兵营运得起 | 一次超过营级（五百人／三百吨）即属大规模 | 终卷前 |
| 不得写大规模空运、不得写长期跨海峡航渡 | 依据由油账改为**船与护航兵力**（#226） | 全域 | 终卷前 |
| 炮弹是闸门（1937 全军平均每门每天约 2.6 发） | 编制数不等于实射数 | **不得写「炮火覆盖」「万炮齐发」**；不得写夜间试射找点（本线炮兵是精打不是猛轰） | 终卷前 |
| 军工直吃钢不超过钢产量一成 | 验算三：1944 年 55 万吨扣军工约 5.5 万吨，余 49 万吨养民用（人均十六公斤） | **不得写「军工吃掉钢产量的一半」** | 战时全程 |
| 不得写全军机械化 | 油、车、路三样共同约束 | 机械化锁「一个军＋若干旅」 | 终卷前 |
| 不得写全军装甲化、不得写骑兵消失 | 复员缩编收车辆最狠（要油、要进口件） | 1950 装甲兵独立、同年骑兵缩编为旅 | 1946 后 |
| 推进速度 20—30 km／日 | 朝鲜山地与补给线所限 | 朝鲜攻势不得写更高 | 1944—1945 |
| 能力边界六条 | ①离了铁路走不远（先写在哪一站下车）；②离了公路走不动、离了天气看不清；③二十吨天花板；④**没有夜战、没有全天候**（**限制范围＝装甲与防空**，防空炮 1944 年前无雷达引导，靠目视与听音；**步兵夜袭不在此列**）；⑤维修与备件是隐形闸门；⑥**任何一格都不得单独决定一场战役的胜负** | 装甲车辆与防空 | 终卷前 |
| 三根绳子不许松 | 钼不顶 88%、铝土不顶电解（**电解的闸门是电不是矿**）、松辽井不顶「无大庆」 | 不得让任何一格解掉既有卡脖子 | 终卷前 |
| 不得称「亚洲最大」／不得写「东北空军全国第一」 | #228 D621 口径：**比的是门类不是吨位** | 一律改「门类齐备、能自相配套的成套工业基地」 | 终卷前 |
| 战时不得新建整座兵工厂 | 本线的产能是老厂加线与三班倒逼出来的，不是新厂铺出来的 | **限制范围＝东北华北核心区**（#265 列明）；**西南、西北与大后方的分厂、迁建与新建可写**，但仍不得写成「建一座新厂就解决产能」 | 战时全程 |
| 航空磁测 | 专用器件拿不到 | 禁写（**航空摄影已放行**，见第八节） | 终卷前 |

## 四、叙事与政治红线

| 条款 | 原因 | 限制范围 | 时间节点 |
|---|---|---|---|
| 不得写内战 | 本线全国统一于联合政府（民国三十一年），1949 联合政府的席位从两个战场的分工起算 | 全域 | 终卷前 |
| **不得写起义／赴台／被俘三类结局** | 本线民国人物结局一律不交代（龙云「不得交代 1953 年之后的事」即其例） | 所有真实历史人物 | 终卷前 |
| 不得写 1953 年之后的成就提前交代 | 不得用「后来他成了……」的口吻写任何人 | 全域 | 终卷前 |
| 汪伪政权在本线不成立（#232 D641） | **出走的前提是「抗战已经无望」这个判断成立**；本线 1938 徐州顶住、1940 华北在奉系手里、两个战场分工已成，**这句话说不出来** | 1940 年起南京不得另立中枢；**必须明写而不能让它悬着** | 1938—1945 |
| 不得写伪满洲国 | 本线无满洲国：**它没能建立一个国家，因为它没能拿下一座城** | 全域 | 终卷前 |
| 台湾、澎湖＝**归还** | 《开罗宣言》《波茨坦公告》下的归还，与朝鲜（作战）、越北（跨国受降）**三者性质分开** | **不得写据点、不得写驻军不还、不得写自决之外的扩张** | 民国三十四年十月接收 |
| 朝鲜＝作战之延伸＋统一受降 | 战后依开罗宣言撤出 | **不作占地**；1946 撤兵不撤援 | 1945—1946 |
| 越北＝跨国受降 | 十六度线以北，**1946 交还法方** | 不得写成据点 | 1945—1946 |
| 缅甸＝配合英军 | 本线不是主攻；**滇西与缅北的分界是国境线不是战场**（松山、腾冲在云南境内，本线担纲） | 缅北不写本线主攻 | 1944—1945 |
| 结局留白（#198） | 设定端**只写输入不写输出**，战役结果由正文结算 | 战役表最后一格一律是「结算项与红线」，不是「结果」 | 终卷前 |
| 桂柳不得写成歼灭战（#195 N48） | **日军是自己走的，我们是在追** | 广西反攻 | 1945 |
| 豫湘桂不得写成有来有回的拉锯 | 这一段是全书最痛的一段 | 派部参战（归第一、第九战区指挥） | 1944 |
| 第一次缅甸战役「惨而不崩」 | 下限不得崩、上限不得胜 | 民国三十一年 | 1942 |
| 不得写成「另一场台儿庄」（万家岭） | 每场胜仗各有其形 | 赣北 | 1938 |
| 中共线：写组织与战场**不点名** | #250 废止「本作不写中共线」；依据 SYNOPSIS 3.1·6.1，**窗口止点是独立口径——党派不再是边界，时间才是** | 敌后战场归敌后，正面战场归本线，两边各记各的账 | 终卷前 |
| 不得写出川抗战之外的第二支远征叙事 | — | 滇系 | 终卷前 |

## 五、身份与地理（#259—#264 立）

| 条款 | 原因 | 限制范围 | 时间节点 |
