# 政治体系

## 一、东北国民促进会

### 1.1 组织定位

- **全称**：东北国民促进会（暂定名，可讨论修改）
- **成立时间**：1929年（小说时间线）
- **性质**：东北-华北根据地的执政核心组织，兼具政党与准政府职能
- **纲领**：“民族复兴、工业建国、军民一体、渐进改革”

### 1.2 组织架构

```
最高领导层（核心委员会）
    ├── 政治部（负责政策制定与干部任免）
    ├── 军事委员会（统辖军队，名义上隶属但实际独立）
    ├── 经济计划委员会（统筹工业与农业政策）
    ├── 宣传教育部（负责舆论、教育、扫盲）
    └── 监察委员会（反腐与纪律检查）
```

### 1.3 发展轨迹

- **初创期（1929-1931）**：以张学良为核心的小圈子智囊团，成员多为讲武堂新生代和留日/留德归国青年
- **扩展期（1932-1936）**：随着华北控制区的扩大，吸收地方精英、知识分子入会，逐步制度化
- **执政期（1937-1945）**：从秘密组织转变为公开执政党，建立各级议会和行政体系

## 二、政治体制

### 2.1 权力结构

- **名义上**：维持“中华民国”旗号，不急于宣布独立建国（政治上更利于团结全国）
- **实际上**：张学良以“东北边防军司令长官”和“国民促进会核心领导人”双重身份掌握实权
- **与南京关系**：前期保持名义隶属（民国二十年间），后期通过“改组国民政府”实现统一

### 2.2 地方治理

- **省-县两级制**：保留原有行政区划，但派遣促进会成员担任关键职位
- **地方议会**：在东北先试点，后推广至华北，吸纳商会、工会、农会代表
- **官僚体系**：以讲武堂毕业生和技术官僚为骨干，逐步取代旧式幕僚和乡绅

## 三、意识形态

### 3.1 核心思想

- **民族主义**：以“抗日救国”为最大公约数，凝聚各派力量
- **实用主义**：不拘泥于意识形态教条，“能推动工业化的就是好政策”
- **渐进改良**：反对激进革命，主张通过立法和政策引导逐步变革

### 3.2 对土地问题的立场

- 不急于宣布“土地国有”或“集体所有”
- 以“减租减息→限田政策→农业合作社”的渐进路径推进
- 用“清算汉奸地产”获取改革合法性，避免直接触动中小地主利益

## 四、关键政治事件（小说时间线）

| 时间 | 事件 | 影响 |
|------|------|------|
| 1928年7月 | 张学良全面接管奉系军政大权 | 结束张作霖时代，开启“少帅时代” |
| 1929年春 | 成立东北国民促进会 | 建立新的政治组织核心 |
| 1931年10月 | 九一八抵抗胜利 | 张学良声望达到顶峰 |
| 1932年 | 出兵华北，控制河北山东 | 形成东北-华北根据地 |
| 1933年 | 推行第一次减租减息令 | 土地改革起步 |
| 1935年 | 东北国民促进会公开化 | 从秘密组织转为执政党 |
| 1940年 | 联合政府成立 | 与各方势力组建抗日联合政府（全国统一以奉系主导） |
| 1942年 | 改组国民政府 | 实现以奉系为主导的全国统一 |

## 五、写作注意事项

- 政治描写避免过于枯燥，可通过具体人物的政治博弈来展现
- 不同派系（老派军阀、新生代技术官僚、知识分子、地方士绅）应有各自的利益诉求和声音
- 避免“主角说一句话所有问题解决”的简化政治描写，展现改革的复杂性和阻力
