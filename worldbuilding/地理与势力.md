# 地理与势力

## 一、核心控制区

### 1.1 东北根据地（1928年起）

| 地区 | 重要性 | 关键城市 |
|------|--------|----------|
| 辽宁 | 政治中心、工业核心 | 沈阳（奉天）、鞍山、本溪 |
| 吉林 | 农业基地、军事要地 | 长春、吉林 |
| 黑龙江 | 资源产区、战略纵深 | 哈尔滨、齐齐哈尔 |
| 热河 | 战略缓冲 | 承德 |

### 1.2 华北控制区（1932年起逐步控制）

| 省份 | 控制时间 | 战略价值 |
|------|----------|----------|
| 河北 | 1932年 | 拱卫东北门户，控制京津 |
| 山东 | 1933年 | 港口（青岛）+ 工业基础 |
| 山西 | 1934年（部分） | 矿产资源 + 军事传统 |
| 察哈尔/绥远 | 1934年 | 对蒙边疆战略 |

### 1.3 扩张区（1937年后）

| 地区 | 控制时间 | 战略价值 |
|------|----------|----------|
| 江苏/上海 | 1938-1940年 | 经济中心、外汇来源 |
| 浙江/福建 | 1940-1942年 | 沿海港口、海军基地 |
| 广东/广西 | 1943-1944年 | 华南门户、南洋贸易 |
| 朝鲜半岛 | 1944-1945年 | 对苏战略、日本后门 |
| 越南北部 | 1945年 | 东南亚据点 |

## 二、重要城市设定

### 2.1 沈阳（奉天）

- **地位**：东北政治、军事、工业中心
- **地标**：张氏帅府（大帅府）、东三省兵工厂、沈阳飞机制造厂、东北大学
- **氛围**：近代化都市，中西合璧，既有日式建筑遗留，也有新兴的欧式风格建筑

### 2.2 哈尔滨

- **地位**：东北第二大城市、对苏贸易门户
- **特点**：俄侨文化浓厚，中东铁路枢纽，冰雪城市
- **剧情功能**：苏联情报人员活跃区，中苏博弈的前线

### 2.3 长春

- **地位**：东北地理中心、铁路枢纽
- **特点**：日据遗留设施较多，民族关系复杂
- **剧情功能**：日本间谍活动频繁区

### 2.4 天津/北京

- **地位**：华北政治中心
- **特点**：租界林立，各方势力交汇
- **剧情功能**：国际外交舞台，情报战中心

## 三、国际势力范围

### 3.1 日本控制区

- 日本本土、朝鲜半岛（日据）、台湾（日据）、伪满洲国（小说中不存在）
- 东南亚殖民地：法属印度支那（越南、老挝、柬埔寨）、荷属东印度（印尼）

### 3.2 西方列强在华势力

- **英国**：控制长江流域利益，上海租界
- **法国**：控制越南（法属印度支那），在华南有利益
- **美国**：在华商业利益，同情中国但孤立主义盛行
- **苏联**：中东铁路利益，出于牵制日本与苏联考虑与东北合作

## 四、地理对剧情的影响

1. **东北的地理优势**：地广人稀、资源丰富、有苏联邻国作为战略后方
2. **华北的地理劣势**：平原为主无险可守，需依靠工业化和军队素质弥补
3. **沿海扩张的必要性**：控制港口才能获得海军力量，进而投射力量到朝鲜和东南亚
4. **气候因素**：东北的严寒可作为军事防御的天然屏障（“冬天是日本人的禁区”）

## 五、写作注意事项

- 每个重要场景应有明确的地理定位，避免“在一个模糊的城市里发生故事”
- 不同地区的文化氛围应有差异（东北的豪爽、华北的厚重、江南的精致）
- 注意1930年代的交通条件：铁路是命脉，公路条件差，长途旅行主要靠火车和马车
