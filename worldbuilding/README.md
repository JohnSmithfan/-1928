本目录收录《奉天1928》小说世界中的一切设定资料，包括政治体系、军事体系、经济体系、地理势力、科技水平、社会文化等。

## 设定原则

1. **历史合理性优先**：所有设定应尽可能贴合1928-1945年的历史背景，避免过度穿越
2. **蝴蝶效应意识**：主角的改变会引发连锁反应，后续设定需与前文保持一致
3. **细节真实感**：武器型号、军衔制度、行政区划等细节应尽量符合历史
4. **开放性**：本世界观为多人协作创作服务，鼓励在框架内自由发挥，但重大设定变更需讨论

## 更新时间线

每次世界观重大调整后，请在对应文件中更新版本号及修改记录。
