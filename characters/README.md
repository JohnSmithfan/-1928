# 角色设定

本目录收录《奉天1928》小说中所有角色的设定文档，包括主要角色、次要角色及历史人物原型。

## 目录结构（2026-10-02 起按角色等级分目录）

```
characters/
  README.md            # 本文件，角色设定总索引与规范声明
  主要角色总览.md       # 角色等级总表（唯一口径）与文件索引
  核心/                 # 33 份
  重要/                 # 25 份
  次要/                 # 17 份（另有 54 位无档者，只列于「主要角色总览」）
  背景/                 # 1 份
```

根目录只留 `README.md` 与 `characters/主要角色总览.md` 两份索引；**角色档案一律置于等级子目录内**，路径写作 `characters/<等级>/<角色名>.md`。

| 等级目录 | 档案数 | 含义 | 处置 |
|---|---|---|---|
| 核心/ | 33 | 有专档、有独立人物弧、跨卷复现、承担不可替代的叙事负载 | 持续给戏，可新增章节 |
| 重要/ | 25 | 有专档、戏份限于某一卷或某一摊事务 | 限场面戏，不再新增独立弧 |
| 次要/ | 17 | 档案转为供查，戏份并入群像或只在同场景点名 | 不扩写，不新增出场 |
| 背景/ | 1 | 停写 | 已有正文留痕不动，后续一律不写 |

> 等级口径以 `characters/主要角色总览.md` 的等级总表为准**核心 33 ＋ 重要 25 ＋ 次要 71 ＋ 背景 1 ＝ 130 ＝ 档数 76 ＋ 无档者 54**（2026-10-07 按实测档数归一：重要 23→25 系 #171 增梅里尼可夫与 D440 增莫德惠；次要 15→17、背景 3→1 系龙云由背景改列次要，D550）。次要段的 71 人里有 54 位无独立档案（11 位从未建档、43 位已并入群像），只在总览表列一行，不在本目录占文件。

**引用写法**：正文、设定文档、报告引用角色档一律写完整相对路径 `characters/<等级>/<角色名>.md`；`characters/主要角色总览.md` 内部的文件索引写相对该文件的 `<等级>/<角色名>.md`。同类角色之间的互引可写同目录文件名（如核心档内写 `characters/核心/万毅.md`）。

## 角色分类

| 分类 | 说明 |
|------|------|
| 历史原型 | 基于真实历史人物改编的角色 |
| 虚构角色 | 完全虚构的人物，用于推动剧情或代表某一群体 |
| 群体角色 | 群像档或临时角色档，不单人建弧 |

**虚构人物四条硬的**：①少写不写虚构人物，能用史实人物顶的位子一律用史实人物；②不把真实历史人物改名虚构化（陈启年、彼得罗夫一类，停写）；③**核心虚构归零**——原甲层仅存的两个虚构（林绍年、马锐）已于批次四（2026-10-01）由米春霖、吕正操、万毅三位史实人物顶位，旧档移入 `_trash/虚构顶位第4批前_2026-10-01/`，此后不得再新增核心虚构角色；④**典型户型的虚构不许顶位**——把一个佃农、一个县城开明地主或一个村里农民协会的会长，换成有名有姓的史实人物，等于把虚构写成伪造，反而是新添一处硬伤。这一层在史实上不可能留下姓名，宁可留着虚构（田茂亭、吴守田一类，判据见 #96 第五节）。

## 角色档案格式规范

每个角色的设定文件应包含以下模块（可根据角色重要性增减）：

- **基本信息**：姓名、年龄、外貌特征、口头禅
- **性格画像**：核心性格特质、优缺点、行为模式
- **背景故事**：出身、成长经历、关键人生事件
- **人物关系**：与其他角色的关系图谱
- **角色弧光**：在本卷/全书中的成长与转变
- **写作注意事项**：视角限制、语言风格、禁忌事项

## 文件命名与落位规范

- **文件名**：`角色名.md`（角色名与 `characters/主要角色总览.md` 表内“角色名”列一致，不加等级前缀）
- **落位**：按等级表所属等级放入 `核心/`、`重要/`、`次要/`、`背景/`；新增角色须**先定等级再建档**，等级未定不建档
- **改名或升降级**：等级变动时用 `git mv` 迁目录，同步 `characters/主要角色总览.md` 的等级总表与文件索引，并在 `CHANGELOG.md` 记一条
- **群体角色**：`群体名.md`（如 `characters/次要/东北军中层军官群像.md`），按群体所属等级落位
