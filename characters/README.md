# 角色设定

本目录收录《奉天1928》小说中所有角色的设定文档，包括主要角色、次要角色及历史人物原型。

## 角色分类

| 分类 | 说明 |
|------|------|
| 历史原型 | 基于真实历史人物改编的角色 |
| 虚构角色 | 完全虚构的人物，用于推动剧情或代表某一群体 |
| 群体角色 | 群像档或临时角色档，不单人建弧 |

## 角色等级（2026-10-01 评估报告 #93，权威口径见 `主要角色总览.md`）

| 等级 | 含义 | 处置 |
|------|------|------|
| 核心 | 有专档、有独立人物弧、跨卷复现、承担不可替代的叙事负载 | 持续给戏，可新增章节 |
| 重要 | 有专档、戏份限于某一卷或某一摊事务 | 限场面戏，不再新增独立弧 |
| 次要 | 不立专档；已有档转为供查，戏份并入群像或只在同场景点名 | 不扩写，不新增出场 |
| 背景 | 停写 | 已有正文留痕不动，后续一律不写 |

**虚构人物四条硬的**：①少写不写虚构人物，能用史实人物顶的位子一律用史实人物；②不把真实历史人物改名虚构化（陈启年、彼得罗夫一类，停写）；③**核心虚构归零**——原甲层仅存的两个虚构（林绍年、马锐）已于批次四（2026-10-01）由米春霖、吕正操、万毅三位史实人物顶位，旧档移入 `_trash/虚构顶位第4批前_2026-10-01/`，此后不得再新增核心虚构角色。；④**典型户型的虚构不许顶位**——把一个佃农、一个县城开明地主或一个村里农民协会的会长，换成有名有姓的史实人物，等于把虚构写成伪造，反而是新添一处硬伤。这一层在史实上不可能留下姓名，宁可留着虚构（田茂亭、吴守田一类，判据见 #96 第五节）。

## 角色档案格式规范

每个角色的设定文件应包含以下模块（可根据角色重要性增减）：

- **基本信息**：姓名、年龄、外貌特征、口头禅
- **性格画像**：核心性格特质、优缺点、行为模式
- **背景故事**：出身、成长经历、关键人生事件
- **人物关系**：与其他角色的关系图谱
- **角色弧光**：在本卷/全书中的成长与转变
- **写作注意事项**：视角限制、语言风格、禁忌事项

## 文件命名规范

- 主要角色：`角色名.md`（如 `张学良.md`）
- 次要角色：`角色名_简述.md`（如 `杨宇霆.md`）
- 群体角色：`群体名.md`（如 `东北军将领群像.md`）
