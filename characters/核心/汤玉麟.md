# 汤玉麟

## 基本信息

- **姓名**：汤玉麟
- **年龄**：**1871年7月生**；1928年**五十七岁**（虚岁五十八），1933年六十二（**【#204 C1】**原记「约47岁」，与史实差十岁）
- **外貌**：身材肥胖，满面红光，常穿华丽的丝绸长衫或军装；手指上戴有多枚宝石戒指；说话时喜欢拍别人的肩膀，笑容满面但眼神精明
- **口头禅**：“少帅年轻有为，老夫佩服！” / “这事儿嘛，好商量，好商量。”
- **身份**：**热河都统**（民国十五年四月任），民国十七年易帜后改称**热河省主席**；奉系老牌军阀，手握重兵但能力平庸，与日本人暗中往来（#204 C1）

## 性格画像

### 核心特质

- **投机主义者**：一生最大的生存策略就是“谁强就跟谁”。从清朝到民国，从袁世凯到张作霖，他始终选择站在“赢家”一边。对张作霖的忠诚是出于利益计算而非真心
- **贪婪自私**：利用职务之便大肆敛财，热河军政系统被他搞得乌烟瘴气。打仗不行，贪钱和保命是一流
- **外圆内方**：表面上对谁都笑脸相迎、好说话，实际上极其精明算计。在奉系老将中属于“会来事”的类型，但缺乏真正的政治远见
- **胆小怕死**：对日本人的态度是“能应付就应付，能不得罪就不得罪”，暗中与日本人保持联系是为了“留后路”

### 优点

- 在奉系元老中资历较深，有一定的军事经验和人脉
- 善于交际，在各方势力之间游刃有余
- 对张作霖本人有 真诚的敬重（虽然不如对权力的追求强烈）

### 缺点

- 军事能力平庸，靠关系上位而非靠战功
- 贪财好色，在军中和民间名声不佳
- 缺乏原则和立场，是典型的“墙头草”
- 对日本人的危险性认识不足，以为“跟日本人做生意”没什么大不了

## 背景故事

汤玉麟1881年生于辽宁义县，出身贫寒。早年投军，凭借投机钻营和逢迎拍马在奉系中步步高升。他是张作霖的同乡和早期部将，在奉系中属于“老兄弟”阶层。

汤玉麟一生最大的特点是“会来事”——他善于察言观色、逢迎上级，在张作霖面前表现得忠心耿耿、唯命是从。张作霖对他虽有不满但念及旧情一直予以重用，任命其为热河都统，掌管热河军政大权。

然而，汤玉麟在热河期间大肆贪污军饷、买卖官职，将热河军队搞得不堪一击。同时，他暗中与日本人保持密切往来，接受日本人的“顾问”和“援助”。这条线在本线没有走到投日那一步：民国十七年八月，他写给日本人的亲笔信被张学良拿获。

在小说时间线中，张作霖皇姑屯遇险后，汤玉麟闻讯从热河赶来奉天“探病”，实则试探张学良的立场。张学良敏锐地察觉到汤玉麟与日本人的暗中往来，设局将其软禁，随后以“勾结外人、图谋不轨”罪将其部下调离热河，由讲武堂出身的年轻将领接管。

## 人物关系

| 关系对象 | 关系性质 | 备注 |
|----------|----------|------|
| 张作霖 | 上下级/老兄弟 | 汤玉麟对张作霖表面忠心，实际是利益交换关系。张作霖对他既用又防 |
| 张学良 | 试探者与被试探者 | 汤玉麟来奉天“探病”实为试探，结果落入张学良的圈套。他是张学良整肃军权的第一个目标 |
| 日本人 | 暗中合作者 | 汤玉麟与日本人保持秘密联系，接受日本人的“援助”和“顾问”，以为可以左右逢源 |
| 奉系老将们 | 同类/被鄙视者 | 其他奉系老将表面上与他称兄道弟，私下里鄙视他的为人 |

## 角色弧光

1. **投机者**（第一卷）：以为张作霖遇险后可以趁机向日本人表忠心，换取自己在东北的新位置
2. **落网者**（第一卷）：被张学良识破阴谋，软禁后试图求饶但无效
3. **牺牲品**（第一卷末）：被张学良以“勾结外人”罪处置，成为震慑全军、树立权威的典型案例
4. **警示**（后续卷次）：其命运成为奉系内部的警示——“少帅不是以前的少帅了，动歪心思的下场就是汤玉麟”

## 写作注意事项

- **避免过度丑化**：汤玉麟虽是反面角色，但应写出其“小人物的生存智慧”——他不是大奸大恶之徒，而是一个在乱世中靠投机求存的庸人
- **喜剧效果**：可以适当安排一些黑色幽默场景，如他被软禁后手忙脚乱地写“检讨书”、试图贿赂看守等
- **历史尊重**：历史上汤玉麟确为奉系老将，热河都统，1933年日军进攻热河时不战而逃，丢了承德，举国声讨，南京下令通缉。但他没有当成汉奸：伪满的委任拒了，同年七月与日方的那一次秘密勾结因部下反对也没有谈成；此后部队被收编、他本人退闲居天津（卒年有两说，民国二十六年五月与民国三十八年二月）

## 民国十七年之后的位子（#228 D627 落值）

**此前本档只说他"被革职软禁"，未交代软禁之后落到哪里，导致第三卷第333章《归葬奉天》写"老帅旧部（张作相、汤玉麟）含泪送别"（1938年）时无法判断他能不能出场。现落值如下：**

| 时点 | 位子 | 说明 |
|---|---|---|
| 民国十七年八月 | 革职、软禁 | 以"勾结外人"罪处置，热河军同时整编（第024章《铁腕整肃》） |
| 民国十七年八月至民国二十年前后 | 软禁 | 软禁地点不出奉天；**此间不得写他任事、会客、递话** |
| **民国二十年前后至终卷** | **释出闲居** | **不再任军政职务、不复出、不带兵、不参议**；居奉天或天津，靠旧日积蓄与一点旧情面过日子。**他此后在书里只剩"一个名字"** |
| 民国二十二年三月 | 热河失守 | **热河是本线丢的，但不是他丢的**——他五年前就已革职。**不得写他弃守承德、不得写他出任任何伪职**（这一条与他是否仍在热河无关，是本线对他的硬口径） |
| 民国二十七年（1938） | 老帅葬礼 | **可出场**：只给**一个名字与一个动作**（名单里的一行、人群中鞠的一个躬），**不给台词、不给职务、不写他复出、不写他与人交谈**。他与热河、与热河军已经没有关系 |
| 卒年 | **不写** | 史实卒年有两说（民国二十六年五月／民国三十八年二月），本线一律不交代，亦不得用"后来他如何"的口吻提前交代 |

**写法要点**：他在后四卷里的功能是**警示的活样本**——不是反派，是一个"还在、但已经什么都不是"的人。别人看见他会想起民国十七年那一案，这就够了。**不得给他任何翻案、洗白、二次起用的戏。**

## 正文依据

- 第004章《暗线初布》：作为热河都统在各站恭候，营造大帅出巡的排场
- 第014章《陆路启程》：沿途迎驾仪式安排妥当，派热河卫队副统领在门外恭候
- 第016章《奉天风云》：心思在保住热河那块地盘；在古北口设有接应站
- 第019章《玉麟来归》：八角台的老底子，与张作霖是把兄弟，比张学良大了整整二十岁
- 第024章《铁腕整肃》：在偏院里来回踱步，急得满头是汗
- 第051章《过冬之策》：被人拿他的旧部来要东西，问给不给
- 第102章《联姻筹备》：给山西的那一桩，说的是阎锡山那边有个侄辈，年纪相当，还没定亲；给热河的那一桩，说的是汤玉麟的次子。
- 第114章《作霖之默》：“热河这一头，汤玉麟那边两个月没报实数了”。
- 第121章《关东军策》：热河的兵是汤玉麟的兵，汤玉麟去年收过东北的饷，也收过南京的委任状，两边都没给准话。
- **结局不预立（P1 补注，#103）**：本线止于 1953。他被革职软禁之后只在旁人转述里出现，不得再给他新的职分，也不得写他的结局
